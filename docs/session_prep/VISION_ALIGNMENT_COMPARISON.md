## ✅ 정렬 완료 (세션에서 확인만)

### Q3 완전 일치 — Ball x Pit 70% + 동방 20% + 오리지널 10%
- 가장 큰 갈등 예상 항목이 완벽 정렬 🎉
- 두 사람 다 "메카닉 우선, 동방은 스킨/설정 수준"에 동의
- **이 합의가 나머지 결정의 기반**

### Q1 자연스러운 위임
- 나비욧드: 동방 IP 잘 모름 → Pass
- kimringo: 동방 잘 앎 → A 선택 + 리드
- **파트 분담의 자연스러운 기초**:
  - **나비욧드** = 게임플레이 / 시스템 / 오리지널 트위스트
  - **kimringo** = 동방 캐릭터 / 스토리 / 팬 정서 / 문화

## ⚠️ 조정 필요 항목 (세션에서 논의)

### Q2. Core fantasy — 뉘앙스 차이

| 나비욧드 | kimringo |
|---|---|
| C만 (창의적 실험이 코어) | **A 메인** + C 보조 (파워 판타지 코어, 실험은 보조) |

**둘 다 C 포함**이라 완전 갈등 X. 논쟁 지점:
- **파워 판타지 메인**이면 → 성장 곡선 밸런싱 우선, "약함→강함" 사이클
- **창의적 실험 메인**이면 → Fusion 조합 자유도 우선, 밸런싱은 유연

**절충 후보**:
- **둘 다 메인** (Ball x Pit 자체도 그럼)
- 우선순위는 실제 개발/플레이테스트 데이터로 조정
- 지금은 "파워 판타지 + 창의적 실험 = 둘 다 코어" 정도로 합의

### ⭐ Q4/Q5 스케일 차이 — 가장 큰 협상 지점

| 항목 | 나비욧드 | kimringo | 스케일 차이 |
|---|---|---|---|
| Q4 상업화 | D 미정 유지 | B 저가 유료 | kimringo가 더 진지 |
| Q5 완성도 | A 프로토타입만 | C Steam 출시 | kimringo가 더 야망 |

**차이의 의미**:
- **나비욧드**: "일단 만들어보고 결정" — 실험/배움 프로젝트 마인드
- **kimringo**: "완성작 만든다" — 진지한 커밋 / Steam 출시 목표

**절충안 (Phase 접근)**:
> **"프로토타입 (Phase 1) → 결과 좋으면 Steam 출시 (Phase 2)"**
> 
> - 나비욧드의 "폐기 가능한 시작점" + kimringo의 "Steam 종착점" 결합
> - 프로토타입은 "폐기 가능한 실험"이 아니라 **"Steam 출시 여부 검증의 마일스톤"**으로 재정의
> - Q4는 D 유지 (프로토타입 후 판단), Q5는 A → **A + C 열어둠** (프로토타입 성공 시 C로)

이렇게 하면 둘 다 만족. **세션에서 이 절충안 논의 우선.**

```
        (나비욧드의 실험 마인드 + kimringo의 진지 완성 절충)

        (자연스럽게 나온 것 정리 → CLAUDE.md 반영 예정)

        (한 사람이 작성 → 상대 리뷰 → merge)
```

⭐ = 시간 가장 많이 쓸 곳 (Q4/Q5).

## 🎭 kimringo가 자기 답변에서 짚은 자기 관찰

> "Q1 vs Q3 긴장 관계: '신사 수호 + 스토리 중심' 프레임을 골랐지만 동방 비중은 20%뿐. 프레임과 실제 콘텐츠 비중이 다를 수 있다"

**나비욧드의 응답 방향 (세션 논의 재료)**:
- 이 긴장은 **정상 + 오히려 강점**
- **프레임(마케팅용 한 줄) ≠ 콘텐츠 비중** 분리는 자연스러움
- 사례:
  - **Balatro** — "포커" 프레임이지만 실제는 조합/카드/조커 시스템 재미
  - **Ball x Pit** 자체 — "Arkanoid" 프레임이지만 실제는 Ball Fusion + 시티빌딩
  - **Vampire Survivors** — "탄막" 프레임이지만 실제는 빌드/오브 실험
- **우리 게임**: 
  - 프레임: "동방 신사 수호" (마케팅, 첫 인상, 팬 유입)
  - 콘텐츠: "Ball Fusion 실험 + 성장" (실제 재미)
  - 이 분리가 오히려 **팬 게임의 정석적 강점**

## 🤝 강한 취향 정리 (세션 시작 시 서로 명확히)

### 나비욧드가 밝힐 것
1. **Ball x Pit 스타일 정면 아레나 + Fusion 시스템**은 코어 — 뷰/메카닉 변경 X
2. **동방 지식 필요한 파트는 kimringo에게 완전 위임** — 캐릭터 선정, 스토리, 대사 등

### kimringo가 밝힐 것
1. **메카닉이 메인, 동방은 그 위 스킨** (Q1/Q3 정리 결과 유지)
2. **파워 판타지가 코어 감정선** (Fusion 실험은 보조로)
3. **저가 유료 + Steam** — 무료 배포 / 완전 오리지널 전환 X

### 겹침 (좋은 신호)
- 둘 다 **메카닉 우선 + 동방은 스킨** 동의 ✅
- 둘 다 **Fusion/실험**을 최소 보조 축으로 인정 ✅
- 둘 다 **Ball x Pit 70% + 동방 20%** 동의 ✅

### 갈등 없는 강한 취향 지점
- 나비욧드의 "정면 아레나 유지" — kimringo도 반대 없음 (Q1에서 아르카노이드 라인 골랐음)
- kimringo의 "파워 판타지 코어" — 나비욧드가 실험(C) 골랐지만 파워 판타지 반대 안 함

**즉 강한 취향들이 모순되지 않음. Q4/Q5 스케일만 진짜 조정 필요.**
